# Arquitectura del Sistema:  [Plataforma de reservas de hoteles] 

## Problema que resuelve 
La plataforma permite conectar a los viajeros con los hoteles que tengan disponibilidad de habitaciones, facilitando la consulta de hoteles, comparación de precios y la realización de reservas de manera directa, sin depender de intermediarios.
